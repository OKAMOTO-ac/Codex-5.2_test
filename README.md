# スケジュール管理アプリ

ブラウザ上で予定を登録・編集できるシンプルなスケジュール管理アプリです。登録した予定は `localStorage` に保存され、ページを再読み込みしても保持されます。

## 機能
- 予定の追加（タイトル / 日付 / 時間 / カテゴリー / メモ）
- 予定の編集・削除
- 日付フィルタとキーワード検索
- 予定件数のカウント表示

## 使い方
1. `app/index.html` をブラウザで開きます。
2. 「予定を登録」フォームから予定を追加します。
3. 予定一覧から編集・削除できます。
4. 「日付で絞り込み」や検索ボックスで予定を絞り込めます。

## ファイル構成
- `app/index.html` : 画面レイアウト
- `app/styles.css` : スタイル
- `app/app.js` : 予定の登録・編集・検索ロジック

## 開発メモ
- データは `localStorage` の `schedule-items` キーに保存されます。
